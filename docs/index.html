🚀 Come sincronizzare e pubblicare su GitHub Pages

Questo sito è una Vanilla SPA Zero-Build: non richiede Node.js, Webpack o processi di compilazione. Ogni volta che viene riassunta una nuova live con l'agente o con lo script, basta eseguire:

py dnd_summarizer.py --build-web
git add docs/
git commit -m "Aggiornato archivio sessioni"
git push

GitHub Pages è configurato per pubblicare direttamente dalla cartella /docs del branch principale.
